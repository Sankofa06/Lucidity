What exists in the repository

Not one finished app.
Two credible foundations.

01

Mira · Swift 6

A polished native shell with one live route.

  • Responsive chat, Inspector, rail, Settings, task and route picker
  • In-memory machine drafts and read-only LM Studio, A1111 and ComfyUI probes
  • Route hydration and LM Studio streaming chat
  • Focused endpoint, inventory, route and streaming tests

Boundary: machine and transcript state are still in memory; Group Chat, Compare, cloud streaming, and much of the supporting library remain planned.

02

Lucidity Fleet · Node + React

A phone-first control path for a private fleet.

  • SQLite orchestrator for session routing and mirrored history
  • MCP and REST diffusion service wrapping ComfyUI jobs
  • Installable PWA for Chat, Images, and fleet state
  • GitLab validation plus optional machine-local deploy jobs

Boundary: this is a self-hosted prototype. Deployment and private-network security depend on the operator's environment; authentication is optional in the current design.

Repository roadmap

Where the work stopped—and the cleanest way back in.

The native task ledger has no in-progress item. Its next ready steps are durable persistence and multi-route chat. Fleet has a staged bring-up guide, but no public CI evidence was available from GitHub.

  1. Built

    First-build foundation

    Native interaction shell, live LM Studio Free Chat, endpoint probes, route hydration, plus the separate Fleet orchestrator, diffusion server, and PWA.

  2. Decision

    Choose the product center

    Decide whether Mira remains the primary native experience, Fleet becomes the product, or the two become explicit clients of one shared control plane.

  3. Next

    Make the native path durable

    Persist configured machines and conversations, then extend the proven one-route chat path to Compare and Group Chat with cancellation and scheduler tests.

  4. Later

    Earn the wider studio

    Build real Personas, Teams, Projects, model-source downloads, cloud routes, App Intents, and live surfaces only after the core ownership boundary is settled.

Original intent

“Chat is the center. All major workflows can begin from chat.”

The strongest idea worth preserving is not a feature list. It is the attempt to make machines, routes, media engines, and diagnostics feel nearby without making setup the product.
