01

CHAT FIRST

Choose a route, then stay with the conversation.

  • Responsive chat workspace for iPhone and iPad
  • Task-first route picker instead of a wall of model names
  • Streaming Free Chat through a selected LM Studio route
  • Inspector and Developer Mode details close at hand

Current scope: this release supports one explicit live LM Studio text route. Group Chat, Compare, persistent transcripts, and cloud streaming remain future work.

02

YOUR ROUTES

See the endpoints behind the friendly name.

  • Add machine display names, hosts, and expected ports at runtime
  • Run read-only probes for LM Studio, A1111/Forge, and ComfyUI endpoints
  • Hydrate discovered routes into Chat, Inspector, Machines, and Library
  • Keep real hosts, keys, and inventories out of the app's public source

Current scope: configured machines and endpoint state are in memory in this release. Mira connects only to routes you explicitly configure.

Release roadmap

A focused first route, then durable work.

Build 7 packages the native foundation for App Store delivery. The next steps are durable machine and transcript storage, followed by carefully expanding the proven one-route chat path.

  1. Built

    Native foundation

    Responsive Chat and Inspector, task and route pickers, runtime machine setup, endpoint probes, route hydration, and live LM Studio Free Chat.

  2. Now

    Build 7 release candidate

    Signed App Store delivery uses the private Silver Surfer Xcode 26.3 runner. Public support and privacy pages describe the current source behavior.

  3. Next

    Make work durable

    Persist configured machines and conversations, then extend the proven route path to Compare and Group Chat with cancellation and scheduling.

  4. Later

    Earn the wider studio

    Expand Personas, Teams, Projects, model sources, cloud routes, media planning, and live surfaces only as their real workflows land.
